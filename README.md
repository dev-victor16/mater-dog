# Mater Dog — Clínica Veterinária 24 Horas (Ibirité - MG)

Site institucional moderno, exclusivo e de alto padrão desenvolvido para a **Mater Dog Clínica Veterinária**, localizada no Setor Alvorada em Ibirité - MG.

Desenvolvido com foco em **cuidado + confiança + proximidade + profissionalismo**, utilizando dados 100% autênticos da clínica, fotos reais e rejeitando completamente templates genéricos de inteligência artificial.

---

## 🌟 Características Principais

* **Identidade Visual Autêntica:** Paleta médica turquesa (`#009E8C`), ardósia escura (`#0D1E24`) e base neutra suave com tipografia *Plus Jakarta Sans*.
* **Design Editorial Anti-Template:** Variedade rítmica de seções, assimetrias intencionais, sem repetição de cards genéricos.
* **Módulo de Urgência & Emergência 24h:** Seção de alto contraste com guia de triagem rápida e canais de ligação e WhatsApp diretos.
* **Fotos Reais da Estrutura:** Imagens autênticas da recepção, consultórios, leitos e salas de ultrassom com *lightbox* interativo.
* **Prova Social Verificada:** Depoimentos reais de tutores obtidos diretamente do Google Business (nota máxima 5.0 com mais de 102 avaliações).
* **SEO e Schema.org:** Marcação semântica completa com dados estruturados `VeterinaryCare` para motores de busca e geolocalização em Ibirité.
* **Mobile-First:** Navegação rápida, menu *drawer* lateral suave e barra inferior de 1-toque para chamadas e mensagens instantâneas.

## 📁 Estrutura de Arquivos

```
├── index.html                   # Estrutura HTML5 semântica e SEO
├── server.js                    # Servidor local nativo em Node.js (porta 3000)
├── assets/
│   ├── css/
│   │   ├── variables.css        # Design tokens (cores, fontes, espaçamentos)
│   │   ├── main.css             # Reset, tipografia e animações de scroll
│   │   ├── components.css       # Botões, pulse 24h, header sticky, FAQ, lightbox
│   │   ├── sections.css         # Hero, sobre, urgência, serviços, galeria, contato
│   │   └── responsive.css       # Regras para tablet, mobile e barra inferior fixa
│   ├── js/
│   │   ├── animations.js        # IntersectionObserver para animações suaves
│   │   ├── gallery.js           # Lightbox com suporte a teclado (Esc) e clique
│   │   └── main.js              # Menu drawer, FAQ expansível e status em tempo real
│   └── images/
│       ├── logo.jpg             # Logotipo oficial circular
│       └── real-clinic/         # Fotografias autênticas da clínica Mater Dog
```

---

## 🚀 Como Executar Localmente

Você pode abrir o projeto diretamente abrindo o arquivo `index.html` em qualquer navegador ou iniciar o servidor local nativo em Node.js:

```bash
node server.js
```

O site estará disponível em:
👉 **http://127.0.0.1:3000/**
